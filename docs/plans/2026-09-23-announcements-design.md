# 首页公告与课程评价入口调整

状态：已实现，基于 2026-09-23 的前后端 `origin/main` 整合。正式部署状态以学校发布清单和实际健康检查为准。

## 范围

- 保留首页轮播、相关链接和原帖子动态卡片区的整体布局；卡片区改为公告，移除首页咕咕。
- 主侧边栏不再显示社区入口。历史论坛、反馈、活动数据和其他页面不做清理。
- 课程工具栏移除“探索”，历史探索 URL 转到课程图谱；历史课程评价 URL 转到课程总览。

## 公告来源与权限

新公告沿用已有 `posts` 与 `post_tags` 结构，使用系统标签 `platform-announcement`。普通用户不能通过发帖 API 添加这个标签；发布、编辑和撤下该类内容都由服务端核验管理员角色。公告列表只读取带此标签的帖子，管理员在独立公告管理页操作。无需数据库结构迁移。

从学校正式站公开帖子历史中人工挑选了 4 条平台更新，分别是 #305（2026-08-18 排课助手迁移）、#270（2025-12-27 排课助手 v2.0.0）、#115（2025-06-23 更新报告）和 #104（2025-06-13 更新报告）。这些原帖没有改动；前端保存只读历史快照，以免开发与正式环境的帖子 ID 不同。历史内容标注原日期和“历史公告”，详情保留原文，并提供英文标题及摘要。普通提问、课程评价、社团招新和活动帖子未列入平台公告。

## 验收

- 首页桌面和手机仍是轮播、相关链接、三列/单列卡片的既有结构；公告卡片和详情在中英文均能阅读。
- 管理员可发布、修改、撤下新公告；普通账号直接调用原发帖接口也不能伪造平台公告。
- 课程工具栏没有“探索”，旧 URL 安全跳转；论坛历史记录未删除。
