# 排课方案日历导出

## 目标与范围

- 基于准备 PR 时最新的 `main`（`4e34ad9`）为当前固定/评分优先方案及已保存方案预览增加 `.ics` 下载。
- 复用原站的操作按钮、主题和中英文文案；访客也能导出本地可见方案，不新增后端接口或日历账号授权。
- 只导出实际选中的班别及其全部讲座/实验/讨论时段，不导出其他候选课、评分、屏蔽时段或用户身份。

## 日期与格式

- 以 `SchedulerLecture.date_ranges` 为真实教学日期来源，起止日期均包含，逐周匹配 `day`，每次实际上课生成一个事件。重复日期去重，不填平分段教学之间的空白。
- 缺少日期时要求用户明确填写补充范围，仅用于缺日期的时段；不从学期编号猜开学日，不用补充值覆盖已有日期。无效数据阻止下载，无时间的班别明确列出。
- 现代广州教学时间按 UTC+8 转换为 UTC，避免导入设备时区影响原始时刻；支持 1992 年起的日期，单段最多 366 天、单次最多 20,000 个事件。
- 按 [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545) 使用 CRLF、TEXT 转义、UTF-8 75 字节折行及稳定 UID。没有邀请、提醒或自动同步。
- 页面提示源数据可能尚未体现节假日/临时调课；这是一次性快照，建议导入单独日历，更新时避免旧课表残留。

## 实现与验收

- `utils/schedulerCalendar.ts`：纯函数校验、日期展开和序列化，具备固定 `now` 的可复现测试入口。
- `SchedulerCalendarExport.vue`：共用导出入口及原生模态对话框（键盘关闭、焦点管理），展示课次数量、日期范围、缺失数据与下载反馈。
- `utils/schedulerCalendarDownload.ts`：浏览器下载与对象 URL 释放；不向服务器发送课程数据。
- 单测覆盖实际事件集合、UTC 时间、分段/重复日期、跨月年/闰日、所选 bundle、多 section、缺失/非法数据、转义与 UID 稳定性；另做 UI 接线与下载测试。
- 跑排课回归、全量测试、i18n 与构建，并检查桌面/手机、明暗主题及实际下载文件。未获批准不 commit/push/发布。
