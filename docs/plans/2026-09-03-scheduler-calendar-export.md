## 本地复验

在仓库根目录使用 Node 22.23.2：

```bash
npm run i18n:check
npm run test:scheduler
npx vitest run --exclude 'tests/deploy/**'
npm test
npm run build
```

Windows 本地启动（仅监听本机，使用公开 dev 课程 API）：

```powershell
$env:NUXT_PUBLIC_API_BASE_URL = 'https://dev.unikorn.axfff.com'
$env:NUXT_PUBLIC_MASCOT_ENABLED = 'false'
$env:NUXT_PUBLIC_AGENT_ENABLED = 'false'
npx --yes --package=node@22.23.2 node node_modules/nuxt/bin/nuxt.mjs dev --host 127.0.0.1 --port 3000
```

打开 <http://127.0.0.1:3000/courses/planner/2610>，添加并启用课程，在原“保存方案”旁点击“导出日历”，核对预览后下载；切换为评分优先模式时先完成计算。补日期表单可使用上面的 `2430` 样本重现。英文入口为 `/en/courses/planner/2610`。

这是一次性课表快照，不是自动订阅；源数据未体现的节假日和临时调课不会被推测。建议导入独立日历并与学校安排核对。浏览器验收后已按仓库约定停止本地 dev server；未提交、推送或发布到公网 dev。
